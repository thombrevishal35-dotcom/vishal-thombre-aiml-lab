# AIML Lab Experiments

12 Python programs for AI/ML lab experiments.

## Programs
1. BFS
2. A* Search
3. Tic-Tac-Toe
4. Arithmetic and statistics
5. Python libraries: Math, NumPy, SciPy, Pandas, Matplotlib, Seaborn
6. Data preprocessing (missing values, encoding, normalization)
7. Linear regression (Auto MPG dataset from OpenML)
8. Logistic regression (Breast Cancer dataset)
9. Naive Bayes (Iris dataset)
10. Decision Tree and Random Forest (Heart dataset from OpenML)
11. K-Means clustering
12. Hierarchical clustering and K-Means comparison

## Setup
Install dependencies:
```bash
pip install numpy pandas scipy scikit-learn matplotlib seaborn
```
Experiments 7 and 10 fetch data online through OpenML, so internet access is required.
Run a program:
```bash
python 01_bfs.py
```
